HTML Inicial

Vamos iniciar criando o HTML inicial, incluir o arquivo style.css e script.js. Nesse projeto será utilizada a biblioteca font-awesome. Para incluir o CSS no HTML podemos ir na página https://cdnjs.com/libraries/font-awesome e copiar a URL da última versão da biblioteca. No momento da escrita desse artigo a versão é a 6.7.2. 

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Snake Game</title>
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.7.2/css/all.min.css" />
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <script src="index.js"></script>
  </body>
</html>

Adicionar Fontes do Google

Ir no site https://fonts.google.com/ e procurar pela fonte "Open Sans". Selecionar a fonte e depois clicar em "Get Font". Então cliar em "Get embed code" e na aba "Web" selecionar a opção "@import" e então "Copy code".

Criar o arquivo style.css e colar a fonte selecionada na primeira linha do arquivo.

HTML Principal

Vamos criar um <div> principal para ser um wrapper para os elementos do jogo. Basicamente são três seções:

  • game-details - local onde é apresentado a pontuação atual do jogar e também a maior pontuação já obtida.
  • play-board - o jogo propriamente dito com a cobrinha e as frutas.
  • controls - mostra os controles para movimentar a cobrinha. As setas são da biblioteca "Font Awesome".
<div class="wrapper">
    <div class="game-details">
        <span class="score">Score: 0</span>
        <span class="high-score">High Score: 0</span>
    </div>

    <div class="play-board"></div>

    <div class="controls">
        <i data-key="ArrowLeft" class="fa-solid fa-arrow-left-long"></i>

Estilos

Vamos abrir o arquivo style.css e iniciar a estilização do nosso jogo.

🌍 Estilos Globais

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
    font-family: 'Open Sans', sans-serif;
}
  • * aplica as regras a todos os elementos da página.
  • margin: 0 e padding: 0: remove espaçamentos padrão.
  • box-sizing: border-box: o tamanho de um elemento inclui bordas e padding.
  • font-family: define Open Sans como fonte padrão.

🖼️ Corpo da Página

body {
    display: flex;
    align-items: center;
    justify-content: center;
    min-height: 100vh;
    background: #e3f2fd;
}
  • display: flex: ativa o layout flexível.
  • align-items: center: centraliza verticalmente.
  • justify-content: center: centraliza horizontalmente.
  • min-height: 100vh: ocupa no mínimo a altura total da tela.
  • background: define um fundo azul-claro agradável.

🎮 Container Principal

.wrapper {
    width: 65vmin;
    height: 70vmin;
    display: flex;
    overflow: hidden;
    flex-direction: column;
    justify-content: center;
    background: #293447;
    border-radius: 5px;
    box-shadow: 0 20px 40px rgba(52, 87, 220, 0.2);
}
  • .wrapper: onde o jogo acontece.
  • vmin: unidades relativas ao menor lado da tela (ótimo para design responsivo).
  • overflow: hidden: evita que conteúdo ultrapasse os limites.
  • flex-direction: column: os elementos internos são empilhados verticalmente.
  • background: tom escuro para contrastar com a área de jogo.
  • border-radius: bordas arredondadas.
  • box-shadow: adiciona uma sombra suave para dar profundidade.

🧾 Detalhes do Jogo

.game-details {

    font-weight: 500;
    font-size: 1.2rem;

  • Estilo para barra de informações do jogo.
  • color: cor de texto clara.
  • font-weight: define peso da fonte (mais espessa).
  • display: flex e justify-content: space-between: distribui pontuação e outros detalhes igualmente nas extremidades.

🟩 Tabuleiro do Jogo

.play-board {
    height: 100%;
    width: 100%;
    display: grid;
    background: #212837;
    grid-template: repeat(30, 1fr) / repeat(30, 1fr);

  • display: grid: cria uma grade.
  • grid-template: 30 linhas e 30 colunas, todos do mesmo tamanho (1fr).
  • Isso permite movimentar a cobrinha e a comida por células bem definidas.
  • background: cor escura que ajuda a destacar a cabeça e a comida.

🍎 Comida da Cobrinha

.play-board .food {

}
  • Define a cor da célula que representa a comida: vermelho vibrante.

🐍 Cabeça da Cobrinha

.play-board .head {
    background: #60cbff;
}
  • Cor da cabeça da cobrinha: azul claro, para se destacar no tabuleiro.

🎮 Controles (visíveis só no mobile)

.controls{
    display: none;
    justify-content: space-between;
}
  • Esconde os controles por padrão.
  • justify-content: space-between: quando visíveis, os botões ficam bem distribuídos.
.controls i {
    padding: 25px 0;

    font-size: 1.3rem;

  • Estilo dos botões de direção (ícones <i>).
  • width: calc(100% / 4): 4 botões com o mesmo tamanho.
  • cursor: pointer: mostra que é clicável.
  • border-right: separa visualmente os botões.

Javascript

Vamos criar a arquivo index.js para iniciar a codificação da lógica do jogo da cobrinha.

Selecionando Elementos do DOM

const playBoard = document.querySelector(".play-board");
const scoreElement = document.querySelector(".score");
const highScoreElement = document.querySelector(".high-score");
const controls = document.querySelectorAll(".controls i");
  • Aqui selecionamos elementos do HTML usando document.querySelector:
  • .play-board: a área do jogo.
  • .score: exibe a pontuação atual.
  • .high-score: exibe o recorde.
  • .controls i: todos os botões dentro da classe controls (para celulares).

Variáveis do Jogo

let gameOver = false;
let foodX, foodY;
let snakeX = 5, snakeY = 5;
let velocityX = 0, velocityY = 0;
let snakeBody = [];
let setIntervalId;
let score = 0;
  • gameOver: indica se o jogo terminou.
  • foodX, foodY: coordenadas da comida.
  • snakeX, snakeY: posição da cabeça da cobra.
  • velocityX, velocityY: direção de movimento da cobra.
  • snakeBody: array com as posições do corpo da cobra.
  • setIntervalId: ID do setInterval para controle.
  • score: pontuação atual.

🏆 Armazenando e Exibindo o Recorde

let highScore = localStorage.getItem("high-score") || 0;
highScoreElement.innerText = `High Score: ${highScore}`;
  • Verifica se há um high-score salvo no navegador.
  • Se não existir, define como 0.
  • Atualiza o texto da pontuação máxima.

🍎 Atualiza a Posição da Comida

const updateFoodPosition = () => {
    foodX = Math.floor(Math.random() * 30) + 1;
    foodY = Math.floor(Math.random() * 30) + 1;
}
  • Gera posições aleatórias de 1 a 30 (colunas e linhas do grid).
  • Math.random() retorna um número de 0 a 1.
  • Math.floor() arredonda para baixo.

💀 Lida com o Fim do Jogo

const handleGameOver = () => {
    clearInterval(setIntervalId);
    alert("Game Over! Press OK to replay...");
    location.reload();
}
  • Para o jogo com clearInterval.
  • Mostra um alert() para o jogador.
  • Recarrega a página para reiniciar o jogo.

🎮 Muda a Direção da Cobra com o Teclado

const changeDirection = e => {
    if (e.key === "ArrowUp" && velocityY != 1) {
        velocityX = 0;
        velocityY = -1;
    } else if (e.key === "ArrowDown" && velocityY != -1) {
        velocityX = 0;
        velocityY = 1;
    } else if (e.key === "ArrowLeft" && velocityX != 1) {
        velocityX = -1;
        velocityY = 0;
    } else if (e.key === "ArrowRight" && velocityX != -1) {
        velocityX = 1;
        velocityY = 0;
    }
}
  • Verifica a tecla pressionada.
  • Garante que a cobra não possa inverter diretamente (por exemplo, ir de cima para baixo).
  • Atualiza a direção da cobra com velocityX e velocityY.

🕹️ Muda a Direção com Botões (Celular)

controls.forEach(button => 
    button.addEventListener("click", () => 
        changeDirection({ key: button.dataset.key }))
);
  • Para cada botão de controle, adiciona um evento click.
  • Simula uma tecla pressionada com { key: button.dataset.key }.

🟢 Função Principal: initGame()

const initGame = () => {
    if (gameOver) return handleGameOver();
  • Se gameOver for true, para tudo e chama handleGameOver().

✅ Renderiza a comida

    let html = `<div class="food" style="grid-area: ${foodY} / ${foodX}"></div>`;
  • Cria a comida dinamicamente usando grid-area para posicionamento.

🍽️ A cobra come a comida?

    if (snakeX === foodX && snakeY === foodY) {
        updateFoodPosition();
        snakeBody.push([foodY, foodX]);
        score++;
        highScore = score >= highScore ? score : highScore;
        localStorage.setItem("high-score", highScore);
        scoreElement.innerText = `Score: ${score}`;
        highScoreElement.innerText = `High Score: ${highScore}`;
    }
  • Se a cabeça da cobra está na mesma posição da comida:
  • Gera nova comida.
  • Adiciona um novo segmento no corpo.
  • Incrementa o score.
  • Atualiza o highScore e salva no navegador.

🧠 Atualiza a posição da cabeça

    snakeX += velocityX;
    snakeY += velocityY;
  • Move a cabeça com base na velocidade/direção.

👕 Move o corpo da cobra

    for (let i = snakeBody.length - 1; i > 0; i--) {
        snakeBody[i] = snakeBody[i - 1];
    }
    snakeBody[0] = [snakeX, snakeY];
  • Move cada parte do corpo para a posição da anterior.
  • A primeira posição vira a nova cabeça.

🚧 Verifica colisões com parede

    if (snakeX <= 0 || snakeX > 30 || snakeY <= 0 || snakeY > 30) {
        return gameOver = true;
    }
  • Se a cobra passar dos limites do grid (1 a 30), o jogo acaba.

🐍 Renderiza a cobra

    for (let i = 0; i < snakeBody.length; i++) {
        html += `<div class="head" style="grid-area: ${snakeBody[i][1]} / ${snakeBody[i][0]}"></div>`;
  • Cria visualmente cada parte do corpo da cobra.

☠️ Verifica colisão com o próprio corpo

        if (i !== 0 && snakeBody[0][1] === snakeBody[i][1] && snakeBody[0][0] === snakeBody[i][0]) {
            gameOver = true;
        }
    }
    playBoard.innerHTML = html;

  • Se a cabeça estiver na mesma posição de alguma parte do corpo, o jogo acaba.
  • Por fim, atualiza o conteúdo da playBoard.

▶️ Inicializa o Jogo

updateFoodPosition();
setIntervalId = setInterval(initGame, 100);
document.addEventListener("keyup", changeDirection);
