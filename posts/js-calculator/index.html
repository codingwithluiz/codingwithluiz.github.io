HTML (Estrutura da Calculadora)

Esta seção cria a estrutura básica da calculadora, definindo a aparência visual e os elementos necessários:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Calculator</title>
  </head>
  <body>
    <!-- Calculator structure -->
    <div id="calculator">
      <input id="display" type="text" readonly />
      <div id="keys">
        <!-- Botões da calculadora, incluindo números, operadores e funções -->
        <button onclick="appendToDisplay('7')">7</button>
        <button onclick="appendToDisplay('8')">8</button>
        <button onclick="appendToDisplay('9')">9</button>
        <button onclick="appendToDisplay('+')" class="operator-btn">+</button>
        <!-- Continuação dos botões até o final -->
        <button onclick="clearDisplay()" class="operator-btn">C</button>
      </div>
    </div>
  </body>
</html>

Explicação dos principais elementos:

  • <!DOCTYPE html> define o documento como HTML5.
  • <html lang="en"> define o idioma como inglês.
  • <head> contém metadados como <title>Calculator</title>, que define o nome da página.
  • <div id="calculator"> é o contêiner principal da calculadora.
  • <input id="display" type="text" readonly /> é o visor da calculadora.
  • <button> com onclick="appendToDisplay('número ou operador')" define cada botão com um valor que é adicionado ao visor ao ser pressionado.

CSS (Estilização da Calculadora)

Nesta seção, damos estilo à calculadora, configurando cores, tamanhos e posições:

<style>
  /* Container da calculadora */
  #calculator {
    background-color: hsl(0, 0%, 15%);
    border-radius: 15px;
    max-width: 500px;
    overflow: hidden;
    font-family: Arial, sans-serif;
  }

  /* Centraliza a calculadora na tela */
  body {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    margin: 0;
    background-color: hsl(0, 0%, 95%);
  }

  /* Estilo do visor */
  #display {
    width: 100%;
    padding: 20px;
    font-size: 5rem;
    color: white;
    background-color: hsl(0, 0%, 20%);
    border: none;
    text-align: left;
  }

  /* Estilo dos botões */
  button {
    width: 100px;
    height: 100px;
    border: none;
    border-radius: 50px;
    background-color: hsl(0, 0%, 30%);
    color: white;
    font-size: 3rem;
    font-weight: bold;
    cursor: pointer;
  }

  /* Layout em grid dos botões */
  #keys {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 10px;
    padding: 25px;
  }

  /* Efeitos de hover e active dos botões */
  button:hover {
    background-color: hsl(0, 0%, 40%);
  }
  button:active {
    background-color: hsl(0, 0%, 50%);
  }

  /* Estilo especial para botões de operadores */
  .operator-btn {
    background-color: orange;
  }
  .operator-btn:hover {
    background-color: hsl(35, 100%, 65%);
  }
  .operator-btn:active {
    background-color: hsl(35, 100%, 75%);
  }
</style>

Explicação dos principais estilos:

  • #calculator: Define o contêiner com bordas arredondadas e uma cor de fundo.
  • body: Centraliza a calculadora vertical e horizontalmente.
  • #display: Define o estilo do visor, onde aparece a expressão matemática.
  • button: Define o tamanho, cor e estilo dos botões.
  • .operator-btn: Aplica um estilo especial aos botões de operadores, como "+", "-", "*", "/".

JavaScript (Funcionalidade da Calculadora)

O JavaScript implementa as ações que acontecem quando o usuário interage com a calculadora.

<script>
  const display = document.getElementById("display");

  function appendToDisplay(input) {
    display.value += input;
  }

  function clearDisplay() {
    display.value = "";
  }

  function calculate() {
    try {
      display.value = eval(display.value);
    } catch (error) {
      display.value = "Error";
    }
  }
</script>

Explicação das funções JavaScript:

  • appendToDisplay(input): Adiciona o valor de input (número ou operador) ao final do conteúdo atual do display.
  • clearDisplay(): Limpa o conteúdo do visor.
  • calculate(): Avalia a expressão matemática no display usando eval(). Caso haja um erro na expressão (como um operador isolado), a função exibe "Error" no visor.
